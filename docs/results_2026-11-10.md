# Results 2026-11-10: rules vs Claude vs Jev on two real SOC 2 reports

**Why the reports are not named.** Both are vendor-published SOC 2 Type 2 reports, and SOC 2 reports are restricted-use
documents. Their names, links, answer keys and per-field outputs are kept on the author's machine only (`private/`,
git-ignored). This page publishes aggregate measurements and the method, nothing copied from either report.

| Report | Used for |
|---|---|
| A | the report the rules extractor was **built from** |
| B | a **held-out** report from a different audit firm; nothing was tuned on it before the run |

Each report has an answer key of 27 checks (facts plus the page each was read from), written from the page text before
any Claude run. Claude: `claude-opus-5-5`, effort high, structured JSON output, one run per route. Jev: `jev-1.14.0`.

## Extraction accuracy and cost

| Reader | Report A | Report B | Factual errors | Reliance findings on report B vs answer key | Cost per report |
|---|---|---|---|---|---|
| Rules (no AI) | 27/27 | **10/27** | many on B | **1 finding, and it is wrong; all 13 real findings missed** | $0 |
| Claude, page text | 25/27 | 26/27 | **0** | **the same 13** | $0.18 / $0.36 |
| Claude, PDF | 24/27 | 25/27 | **0** | **the same 13** | $0.51 / $1.19 |

Every Claude miss was a page citation or spelling where the cited page also states the value. Total Claude spend: $2.25.

On report B the rules extractor failed silently: it returned wrong values rather than "not found". Its worst error read
all five trust services categories as in scope when only one was, which would tell a reviewer that a category they rely
on is covered when it is not.

## What cross-checking two readers caught

1. **A bug in the rules extractor** (report A): it counted a legend sentence as a test result. Fixed, with a test.
2. **A mistake in the answer key** (report B): the key had 0 non-clean test results; both Claude routes found 7 results
   reading "No testing performed" (controls not tested because the triggering event never occurred). The key was
   corrected after the run, and the correction is recorded with it. Untested controls are not evidence that controls work.

## Jev

**On real disagreements** (report B, rules vs Claude): 12 questions, 11 settled correctly, 1 sent to a person, 0 wrong.
On report A it received no questions: once the bug was fixed, the two readers agreed on every fact.

**Planted-error test** (both reports): true values from the answer keys plus deliberately wrong values (wrong report
type, wrong opinions, categories not in scope, decoy providers, including names that appear elsewhere in the report but
not on the page being checked). Production question wording, unchanged. 46 questions.

| Thresholds (yes / no) | True accepted | True to person | **True rejected** | Planted rejected | Planted to person | **Planted accepted** |
|---|---|---|---|---|---|---|
| 0.8 / 0.2 (in use) | 20 / 21 | 1 | **0** | 23 / 25 | 2 | **0** |
| 0.7 / 0.3 | 21 / 21 | 0 | **0** | 23 / 25 | 2 | **0** |

Lowest probability on a true value: 0.76; highest on a planted value: 0.43. The two planted values sent to a person were
marked hard before the run: a scope page that names all five categories in one sentence and lists three as applicable
in the next. Jev answered about 0.4 for both, which is the right answer for a page that contradicts itself.

## Limits

- Two reports, one run per route; Claude's output can vary between runs, and one Jev answer near a threshold moved
  from 0.23 to 0.20 between runs.
- The answer keys were read from the page text by Claude Code, not yet checked by a person; one needed a correction.
- The rules extractor was not changed after seeing report B; 10/27 is its score on an unseen report.
